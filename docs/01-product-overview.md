# 01 · Product Overview

## The problem in one line
Developers learning many technologies at once lose track of *what* they planned to study, *how long* they actually studied, and whether they are progressing — leading to overload and burnout.

## What Focus OS is
A **personal learning operating system** that:

```
PLAN  ──►  FOCUS  ──►  TRACK  ──►  REVIEW  ──►  IMPROVE
  │            │            │           │            │
  │            │            │           │            └─► Statistics
  │            │            │           └─► Daily Review
  │            │            └─► Session History
  │            └─► Focused Timer (planned vs actual)
  └─► Daily Planner
```

## Who it's for
- **Primary:** Software developer learning 3+ technologies in parallel.
- **Secondary:** Self-taught learners, bootcamp students, anyone juggling multiple study tracks.

## What it is NOT
- ❌ Not a Pomodoro app.
- ❌ Not a habit tracker (though it has streaks).
- ❌ Not a course platform.
- ❌ Not an AI assistant (V1).

## Core philosophy
| Principle | Meaning |
|-----------|---------|
| **Planned ≠ Actual** | Two separate numbers, always visible. |
| **One thing at a time** | The session screen is minimal. |
| **No guilt** | Short days are recorded honestly, never punished. |
| **Consistency over intensity** | Streaks reward showing up, not grinding. |
| **Offline first** | A dropped session is a lost moment — never lost data. |
| **AI-ready** | Data model is shaped so future AI can reason over it. |

## Tone of the product
> *"You completed 2 hours today. You had a 6-hour plan. Consider reviewing tomorrow's workload."*

Not:
> ~~"You failed your goal."~~

## Success criteria (for the user)
1. Opens the app, sees today's plan in **< 3 seconds**.
2. Starts a session in **< 10 seconds** (Quick Start).
3. App stays accurate even with the phone locked for an hour.
4. Closes the week knowing **exactly** what they studied and where time went.
